## 🧭 How I work

- **Derive first, then use the library.** I implement the maths before reaching for a package.
- **Fix the real problem, not the symptom.** For example, I tuned decision thresholds on a heavily imbalanced dataset instead of oversampling.
- **Ship it separately.** Model-serving APIs and dashboards run as independent services, as they would in production.
- **Be honest in the docs.** My READMEs list known limitations and what's next.
